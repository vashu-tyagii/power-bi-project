# \# 📊 Machav E-Commerce Sales Dashboard (Power BI)

# 

# An interactive, enterprise-grade business intelligence dashboard built to track, analyze, and visualize comprehensive e-commerce sales performance, profitability trends, and customer-level metrics using Power BI\[cite: 8, 10].

# 

# \---

# 

# \## 🚀 Project Overview

# This project provides stakeholders with real-time visibility into vital e-commerce metrics—such as total revenue, profit margins, order quantities, and average order value (AOV). Designed with a sleek dark-mode corporate UI, it leverages robust data modeling and custom DAX measures to enable seamless multi-dimensional drill-downs by region, payment method, category, and time periods\[cite: 8, 10].

# 

# \---

# 

# \## 🛠️ Key Features \& Learnings

# \* \*\*Interactive Data Visualization:\*\* Implemented a diverse suite of customized visuals including bar charts, donut/pie charts, line \& stacked column charts, KPIs, and formatted slicer navigation\[cite: 8, 10].

# \* \*\*Advanced Filtering \& Slicers:\*\* Custom-formatted tile slicers (Quarterly/Temporal filters) optimized for dark-theme UI responsiveness and seamless cross-highlighting\[cite: 8, 10].

# \* \*\*Dynamic Calculations:\*\* Utilized core and advanced DAX formulas for computing total sales, net profits, quantities, and performance metrics dynamically.

# \* \*\*User-Driven Parameters:\*\* Configured relationships, table joins, and data manipulation workflows to enable user-driven parameters for exploratory data analysis\[cite: 10].
